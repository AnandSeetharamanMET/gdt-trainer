# GD&T Trainer

A free, interactive, browser-based trainer for Geometric Dimensioning & Tolerancing — starting with **true position**, **MMC bonus tolerance**, and **datum shift**.

Built by [Anand Seetharaman](https://anandseetharamanmet.github.io) (BS Mechanical Engineering Technology, CSWP).

**Live site:** https://anandseetharamanmet.github.io/gdt-trainer/

## Learning journal
I built this with zero prior coding experience, learning as I went. Follow along in the [journal](journal/README.md).
